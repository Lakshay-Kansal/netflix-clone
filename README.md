# Netflix Clone with HTML & CSS (Harry Assignment)

## Project Overview

This project is a clone of the **Netflix** homepage, created using **HTML** and **CSS** as part of a Harry assignment. The goal was to replicate the look and feel of Netflix's homepage, including the layout, typography, and image content, with a focus on simplicity and responsiveness.

## Features

- **Responsive Design**: The layout adjusts to different screen sizes, ensuring a seamless experience across devices (desktop, tablet, and mobile).
- **Header**: Includes a navigation bar with links for accessing various sections of the Netflix site (such as Home, Movies, TV Shows).
- **Hero Section**: Displays a large featured banner with a title and a play button, mimicking the Netflix homepage's hero area.
- **Movie Row Sections**: Showcases different categories of movies with thumbnail images.
- **Footer**: Contains additional links for terms, privacy policies, and more.

## Code Explanation

- **index.html**: Contains the HTML structure of the website. It includes the header, hero section, movie rows, and footer.
- **css/style.css**: Includes the styling rules for the webpage, focusing on layout, colors, and responsiveness.

### Key CSS Techniques
- **Flexbox**: Used to create flexible layouts, particularly for the movie row sections.
- **Positioning**: Applied to position elements such as the navigation bar and the play button within the hero section.
- **Media Queries**: Ensures the website is responsive, adapting to different screen widths (for mobile, tablet, and desktop).
- **Background Images**: Netflix-style background images for the hero section and the footer.

## Usage Instructions

1. Clone the repository using the following command:
   ```
   git clone https://github.com/jalal1122/Netflix-Clone-with-Html-Css-Harry-Assignment.git
   ```

2. Navigate to the project directory:
   ```
   cd Netflix-Clone-with-Html-Css-Harry-Assignment
   ```

3. Open the `index.html` file in any modern web browser to view the clone in action.

4. To make changes or further customize the clone, edit the `index.html` and `css/style.css` files. You can replace images in the `images/` folder with your own or update the content as needed.
